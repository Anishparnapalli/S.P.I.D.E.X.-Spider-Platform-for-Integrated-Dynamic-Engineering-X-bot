# S.P.I.D.E.X.-Spider-Platform-for-Integrated-Dynamic-Engineering-X-bot
S.P.I.D.E.X. (Spider Platform for Integrated Dynamic Engineering X-bot) is a Bluetooth-controlled quadruped robot featuring a 12-servo legged architecture driven by inverse kinematics. SPIDEX demonstrates stable, bio-inspired locomotion across multiple gaits such as forward, backward, and turning movements.
